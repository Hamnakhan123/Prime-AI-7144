# Milestone 6 · Project Report, Presentation and Viva

> [Capstone Project](../../README.md) › **Milestone 6** · Suggested timing: Week 6

**Goal:** document the project professionally and demonstrate that every member understands it.

## Tasks – step by step

1. Write the **project report** in MS Word using the [report template](project-report-template.md) – include screenshots,
   diagrams, code excerpts with explanations, the test table and each member's contribution.
2. Prepare a **10-minute presentation**: problem & audience, live demo (phone + desktop), technical highlights, Git history,
   testing, lessons learned. Every member presents a part.
3. Rehearse the **viva**: each member should be able to explain and change any part of the code (see the sample questions
   on the capstone overview page).
4. Final checks: README complete (description, screenshots, live link, features, team, how to run), release tag, report
   uploaded.

## Deliverable
Project report (MS Word), presentation slides, final repository and live site.

## Acceptance checklist
- [ ] Report follows the template, with screenshots and test evidence
- [ ] Contribution table agrees with the Git history
- [ ] Every member presents and can answer code questions
- [ ] Repository README is complete

<details><summary>💡 Hint – commands that make great viva evidence</summary>

```bash
git shortlog -sn                 # commits per member
git log --oneline --graph --all  # branch and merge history
git log --author="Areeba" --oneline
```
