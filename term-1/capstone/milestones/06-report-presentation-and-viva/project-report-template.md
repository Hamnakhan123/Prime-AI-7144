# Project Report Template – Term 1 Capstone Project

> Prepared by **Hamna Zahid Khan**, Junior Lecturer · Write the final report in **MS Word** using these headings.

## Cover page
Project title · Team name · Members (name, roll number) · Course and term · Lecturer · Submission date · Live site URL ·
Repository URL

## 1. Introduction (½ page)
Problem/opportunity, target audience, objectives of the website.

## 2. Requirements
- User stories (from Milestone 1)
- Functional requirements (what the site does) and non-functional requirements (responsive, accessible, fast)

## 3. Design
- Sitemap (diagram) and wireframes (phone + desktop)
- Colour palette, typography, logo
- Data design: structure of `js/data.js` items

## 4. Implementation
For each page: purpose, screenshot, key HTML5/Bootstrap structures used.
Key JavaScript/jQuery features with **short code excerpts and explanations** (search/filter, validation, localStorage,
brief-specific feature).

## 5. SEO and accessibility
Titles/descriptions table, keywords, robots.txt/sitemap, alt text and labels approach, Lighthouse scores (screenshots).

## 6. Testing
Test table (ID, page, steps, expected, actual, pass/fail), browsers/devices tested, bugs found and how they were fixed,
`npm run check` and `npm test` output.

## 7. Version control and teamwork
Branching strategy, pull-request reviews, screenshot of the Git graph, contribution table:

| Member | Responsibilities | Main pages/features | Commits / PRs |
|---|---|---|---|
| | | | |

## 8. Conclusion
What was achieved, limitations, future improvements, what each member learned.

## 9. References
Images and icons (with licences), libraries (Bootstrap 5.3, jQuery 3.7), any tutorials or AI tools used (with how they were
used – follow your course's AI policy).

## Appendices
User manual (how to use the site), full test results.
