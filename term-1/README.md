# Term 1 · Web Foundations & Productivity

> [Prime AI – Software Engineering with AI](../README.md) › **Term 1**

Term 1 builds the foundations every software engineer needs: professional productivity tools, then hand-written HTML5, CSS3 and JavaScript websites, responsive frameworks, search-engine optimisation and version control with Git. It closes with a capstone where you design, build and publish a complete responsive website.

## 🚀 How to work through this term

1. Take the modules in the order above; later modules build on earlier ones.
2. Inside each module, follow the sessions in order and run the files in its `code/` folder.
3. Finish every module with its practice test before moving on.
