# AI prompt library and log

> Prepared by **Hamna Zahid Khan**, Junior Lecturer

## Prompt library (copy, then add your own context)

| Task | Prompt |
|---|---|
| Explain code | "Explain what this function does line by line, and list any edge cases it does not handle." |
| Write tests | "Write node:test unit tests for this function, including edge cases: empty input, wrong types, boundaries." |
| Commit message | "Write a Conventional Commit message (type(scope): summary ≤ 72 chars, then a short body explaining why) for this staged diff." |
| PR description | "Summarise these commits as a pull-request description with sections: What, Why, How to test, Screenshots." |
| Git help | "I committed to main instead of a new branch and have not pushed. How do I move the commit to a new branch? Explain each command." |
| README | "Draft a README for a Bootstrap + jQuery site with: description, features, how to run, live link placeholder, tech stack." |
| Security review | "Review this code for security problems (XSS, injection, secrets) and explain fixes." |
